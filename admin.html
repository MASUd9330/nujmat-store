نجمة الخليج

التوكن محفوظ في متصفحك فقط ولا يُرسل لأي جهة خارجية. تحتاج صلاحية repo على مستودع MASUd9330/nujmat-store.

كيف أحصل على التوكن؟

كيف تحصل على GitHub Token

  1. اذهب إلى github.com/settings/tokens
  2. اضغط Generate new token (classic)
  3. اكتب وصف: nujmat-store-admin
  4. حدد صلاحية repo (كامل)
  5. حدد مدة الصلاحية: 90 يوم (الأفضل)
  6. اضغط Generate token
  7. انسخ التوكن فوراً (لن تراه مرة أخرى)
  8. الصقه في الحقل أعلاه واضغط دخول

ملاحظة: التوكن اللي استخدمناه لرفع الملفات (الموجود في كود Git remote) مختلف — لا تشاركه. اعمل توكن جديد بإذن repo فقط.
